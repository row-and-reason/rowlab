---
title: What rowlab is
description: rowlab labels, extracts and rewrites tabular data with AI, one question per row.
---

rowlab asks a question of every row of a dataset and writes the answers as new columns. Add a CSV,
JSON, JSONL or Parquet file, write the question from the row's own columns, try it on twenty rows,
then run it on all of them. The result is a new dataset: the selected rows of the original, with the answer
columns added.

It is open source (Apache-2.0). Run it on your own machine with one command, on your own servers
with Postgres and S3, or use the hosted version at [app.rowlab.dev](https://app.rowlab.dev).

## Three ways in

- **The web app**, for looking at data and trying questions.
- **The API**, for scripts: everything the app does is an endpoint. See the [API reference](/api/).
- **MCP**, for agents: the same work as tools, with [one skill](/agents/skills) that teaches the workflow.
